- Images in mail now load by themselves, so messages look the way the sender designed them. Tracking pixels are still blocked, and Settings → Mail → Images in mail can switch back to Ask first.
- An image that can't load leaves empty space instead of a broken-image icon, and images open instantly the second time.
- Settings is now a page in the main window, with new Mail and Layout sections and keyboard shortcuts you can change.
- Selected messages are a quiet fill instead of an outline.
- Designed emails no longer look washed out in dark mode.
- Safety fixes: an email can no longer draw over Tern's own controls or change Tern's fonts.
